# STREAMBOX

STREAMBOX is a video-on-demand web application with a TV-style ("10-foot") interface: a featured hero, horizontal content rows, title details, search and a full-screen HTML5 player. It was built for desktop browsers and is controlled with a mouse or with the keyboard arrow keys, which stand in for a TV remote's D-pad.

The application is being prepared for a Smart TV release. The reference device for that release is the **Samsung NU7100 (2018 model, Tizen 4.0)**. The TV work items are tracked separately from this README.

All catalog data, artwork and video are fictional and generated locally, so the app needs no network services, API keys or accounts.

---

## Requirements

- **Node.js 20 or later** (tested with Node 23)
- **npm 10 or later**
- A current desktop **Google Chrome** for development

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173. The UI is designed for a **1920 × 1080** viewport. For the most representative view, use a full-screen browser window or Chrome DevTools device toolbar set to 1920 × 1080. Smaller desktop windows are supported with a reduced layout.

To open the dev server from another device on the same network (for example a TV browser), run `npm run dev -- --host`.

## Features

- **Home**: featured hero, plus rows for Continue Watching (with progress), Trending Now, Popular Movies, Recommended For You, Documentaries and Recently Added, followed by genre rows covering the rest of the catalog.
- **Details** (`/movie/:id`): backdrop, title, genre, release year, runtime, rating and synopsis, with Play and Back actions.
- **Search** (`/search`): case- and accent-insensitive title search, with the query kept in the URL (`?q=`).
- **Player** (`/watch/:id`): play, pause and resume, seeking, a progress bar, current time and duration, and Back to details. The controls auto-hide during playback.
- Friendly screens for unknown titles and unknown routes.

## Controls

| Key | Home | Details | Player |
| --- | --- | --- | --- |
| ← → | Move between titles in a row | Move between Play and Back | Seek −10 s / +10 s |
| ↑ ↓ | Move between rows | — | Show controls |
| Enter | Open the focused title | Activate the focused button | Play / Pause |
| Space | — | Activate the focused button | Play / Pause |
| Escape | — | Back | Back to details |

Escape is the desktop stand-in for the remote's **Back** key. On Search, Escape returns to the previous screen.

Everything can also be operated with the mouse. Row arrows appear when you hover over a row, and the header links are clickable. Remote-style navigation covers the content rows on Home. The header and the hero buttons are operated with the mouse or with Tab/Enter.

## Data and assets

- `src/data/movies.json` holds 400 fictional titles with stable IDs (`sbx-0001` … `sbx-0400`). It is generated by `scripts/generate-catalog.mjs` from a fixed seed, so regenerating it produces the same catalog.
- Editorial curation (featured title, Trending Now) lives in `src/data/editorial.ts`. The demo profile's viewing history lives in `src/data/watchHistory.ts`.
- Posters and backdrops are generated SVG artwork. The two demo videos are synthetic test streams rendered with ffmpeg. No third-party or copyrighted media is included.

## Testing

```bash
npm test
```

The suite covers the catalog and search logic, Home rendering and basic remote navigation, the details screen, search and routing between screens. Tests render the full route tree with an in-memory router (see `tests/renderApp.tsx`).

## Browser support

The app is developed and tested in current desktop Chrome. Support for the Smart TV reference device has not been validated yet.
